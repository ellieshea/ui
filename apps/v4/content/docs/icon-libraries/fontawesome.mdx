## Overview

Font Awesome is a simple, clean, and rounded icon library with thousands of icons. shadcn/ui now supports Font Awesome as a first-class icon library option.

## Installation

Font Awesome is automatically installed when you initialize a project with the Font Awesome icon library selected:

```bash
npx shadcn@latest init --iconLibrary fontawesome
```

Or add it to an existing project:

```bash
npm install @fortawesome/react-fontawesome @fortawesome/fontawesome-svg-core @fortawesome/free-solid-svg-icons @fortawesome/free-brands-svg-icons
```

## Supported Icon Sets

- **Solid Icons**: `@fortawesome/free-solid-svg-icons` (default)
- **Brand Icons**: `@fortawesome/free-brands-svg-icons`

## Usage

### With IconPlaceholder

When using Font Awesome as your icon library in `components.json`, the `IconPlaceholder` component automatically uses Font Awesome:

```tsx showLineNumbers
import { IconPlaceholder } from "@/app/(create)/components/icon-placeholder"

export function MyComponent() {
  return (
    <IconPlaceholder
      fontawesome="faHome"
      className="h-5 w-5"
    />
  )
}
```

The `IconPlaceholder` will be automatically transformed to use Font Awesome when you add components.

### Direct Usage

You can also use Font Awesome icons directly in your components:

```tsx showLineNumbers
import { FontAwesomeIcon } from "@fortawesome/react-fontawesome"
import { faHome, faCog, faBell } from "@fortawesome/free-solid-svg-icons"

export function MyComponent() {
  return (
    <div className="flex gap-4">
      <FontAwesomeIcon icon={faHome} className="h-5 w-5" />
      <FontAwesomeIcon icon={faCog} className="h-5 w-5" />
      <FontAwesomeIcon icon={faBell} className="h-5 w-5" />
    </div>
  )
}
```

## Icon Naming

Font Awesome icons use the naming convention `fa` + PascalCase icon name:

```tsx showLineNumbers
// Solid icons
import {
  faHome,
  faSearch,
  faUser,
  faArrowRight,
  faCheck,
  faX,
} from "@fortawesome/free-solid-svg-icons"

// Brand icons
import {
  faGithub,
  faTwitter,
  faLinkedin,
  faFacebook,
} from "@fortawesome/free-brands-svg-icons"
```

## Styling

Font Awesome icons can be styled using Tailwind CSS:

```tsx showLineNumbers
<FontAwesomeIcon icon={faHome} className="h-4 w-4" />
<FontAwesomeIcon icon={faHome} className="h-6 w-6" />
<FontAwesomeIcon icon={faHome} className="h-8 w-8" />

<FontAwesomeIcon icon={faHome} className="text-red-500" />
<FontAwesomeIcon icon={faHome} className="text-blue-500" />
```

## In Components

### Button with Icon

```tsx showLineNumbers
import { FontAwesomeIcon } from "@fortawesome/react-fontawesome"
import { faArrowRight } from "@fortawesome/free-solid-svg-icons"
import { Button } from "@/components/ui/button"

export function ButtonWithIcon() {
  return (
    <Button>
      Submit
      <FontAwesomeIcon icon={faArrowRight} className="ml-2 h-4 w-4" />
    </Button>
  )
}
```

### Navigation Menu

```tsx showLineNumbers
import { FontAwesomeIcon } from "@fortawesome/react-fontawesome"
import {
  faHome,
  faCog,
  faUsers,
  faChartBar,
} from "@fortawesome/free-solid-svg-icons"

export function NavMenu() {
  const items = [
    { icon: faHome, label: "Home" },
    { icon: faChartBar, label: "Analytics" },
    { icon: faUsers, label: "Users" },
    { icon: faCog, label: "Settings" },
  ]

  return (
    <nav className="space-y-2">
      {items.map((item) => (
        <a
          key={item.label}
          href="#"
          className="flex items-center gap-3 rounded-lg px-4 py-2 hover:bg-gray-100"
        >
          <FontAwesomeIcon icon={item.icon} className="h-5 w-5" />
          <span>{item.label}</span>
        </a>
      ))}
    </nav>
  )
}
```

## Configuration

To use Font Awesome as your default icon library, set it in `components.json`:

```json title="components.json"
{
  "iconLibrary": "fontawesome",
  // ... rest of your config
}
```
